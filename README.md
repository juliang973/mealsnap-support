# MealSnap GitHub Pages Website

Diese kleine Website enthält:
- `index.html` – Startseite
- `support.html` – Support-Seite
- `privacy.html` – Datenschutzerklärung

## So veröffentlichst du sie mit GitHub Pages

1. Neues GitHub-Repository anlegen, z. B. `mealsnap-site`
2. Diese Dateien hochladen
3. In GitHub auf **Settings > Pages** gehen
4. Unter **Build and deployment** als Source **Deploy from a branch** wählen
5. Branch `main` und Ordner `/root` auswählen
6. Speichern
7. Nach kurzer Zeit ist die Seite unter deiner GitHub-Pages-URL erreichbar

## Wichtiger Hinweis

Passe die E-Mail-Adresse und ggf. den Verantwortlichen in `privacy.html` und `support.html` an, falls nötig.
